# 🎵 Music Library / Playlist Manager (WEEKLY OOP PROJECT)

## 📌 Project Overview
This is a simple Music Library / Playlist Manager system.  
It allows users to add songs and podcasts, manage a playlist, and interact with the system through a console-based menu.

---

## 🚀 Features

- 🎶 Add Songs to playlist
- 🎙️ Add Podcasts with episode tracking
- 📋 View full playlist
- 🔁 Dynamic storage using ArrayList
- 🧠 Object-Oriented Design (OOP principles applied)
- ⚠️ Input validation using exception handling (try-catch)
- 🎛️ Interactive menu using Scanner input

---

## 🧠 OOP Concepts Used

This project demonstrates the following OOP principles:

- ✔ Encapsulation (private fields with controlled access)
- ✔ Constructors (object initialization)
- ✔ Inheritance (`Song`, `Podcast` extend `MusicItem`)
- ✔ Method Overriding (`play()` method)
- ✔ Polymorphism (treating different objects as `MusicItem`)
- ✔ Abstraction (interface `Playable`)
- ✔ Access Modifiers (private, protected, public)
- ✔ Packages (organized code structure)
- ✔ ArrayList (dynamic data storage)
- ✔ Exception Handling (try-catch for input safety)
